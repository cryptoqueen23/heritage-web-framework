# WordPress starter

This is an initial, generic theme scaffold, not a finished site or a full WordPress installation.

To preview: install WordPress locally (WordPress Studio or Local), copy `theme/heritage-editorial` into `wp-content/themes/`, activate it under Appearance > Themes, then configure a Primary Menu and a static home page in Settings > Reading.

GitHub tracks the theme. The WordPress database, uploaded media and private configuration are separate and must be backed up securely. Traditional WordPress cannot be hosted directly on Vercel.
